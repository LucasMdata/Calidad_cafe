# Calidad_cafe
Análisis de calidad de café según dataset https://www.kaggle.com/datasets/fatihb/coffee-quality-data-cqi. Se realiza un dashboard sencillo para saber cuales son los países con mayor promedio de calidad. Cual es el máximo.
Y como afecta al ároma el metodo de procesado.
Se elabora un data warehouse desde el dataset estático en SQL.
